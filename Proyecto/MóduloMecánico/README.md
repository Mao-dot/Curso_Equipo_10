# Módulo mecánico

Aquí se documentará el diseño mecánico y la fabricación de las piezas del proyecto.

## Archivos esperados

- modelos editables de CAD;
- archivos de intercambio o fabricación (`.step`, `.stl`, `.dxf`, según corresponda);
- planos y dimensiones críticas;
- materiales y parámetros de fabricación;
- instrucciones de ensamblaje y verificación.

Indicar siempre la herramienta, versión y unidades utilizadas.
