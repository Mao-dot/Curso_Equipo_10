# Proyecto

Esta carpeta contendrá todos los archivos necesarios para comprender y reproducir la solución desarrollada por el equipo.

## Módulos

- [`MóduloSoftware/`](MóduloSoftware/): código fuente, dependencias e instrucciones de ejecución.
- [`MóduloMecánico/`](MóduloMecánico/): modelos 3D, planos y parámetros de fabricación.
- [`MóduloElectrónico/`](MóduloElectrónico/): esquemas, lista de componentes, PCB y archivos de fabricación.

Cada módulo debe explicar en su README:

1. Qué función cumple dentro del proyecto.
2. Qué herramientas o versiones se utilizaron.
3. Cómo abrir, fabricar, ejecutar o verificar sus archivos.
4. Cómo se conecta con los otros módulos.
