# Módulo electrónico

Aquí se documentará el diseño electrónico del proyecto.

## Archivos esperados

- esquema electrónico en su formato editable y en PDF;
- lista de materiales (BOM);
- diseño de PCB, si corresponde;
- archivos Gerber y parámetros de fabricación;
- instrucciones de conexión, montaje y prueba.

Indicar siempre la herramienta y versión utilizadas para generar los archivos.
