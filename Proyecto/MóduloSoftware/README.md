# Módulo de software

Aquí se documentará el software o firmware desarrollado para el proyecto.

## Contenido esperado

- código fuente dentro de [`Código fuente/`](C%C3%B3digo%20fuente/);
- dependencias y versiones;
- instrucciones de configuración, compilación y ejecución;
- pruebas realizadas y resultados esperados;
- descripción de la comunicación con los módulos electrónico y mecánico.

No incluir credenciales, claves privadas ni archivos generados por la compilación.
